# nextjs-pages-ci

기능 없는 간단한 Next.js 서비스를 GitHub Pages에 배포하며, 그 과정에 필요한 GitHub Actions 워크플로(CI, 배포, 실패 분석)를 직접 작성하는 학습 프로젝트.

## 계획

| 단계 | 내용 |
| ---- | ---- |
| 0 | 저장소 준비 |
| 1 | 앱과 테스트 |
| 2 | CI 워크플로 (`ci.yml`) |
| 3 | 정적 내보내기 |
| 4 | 배포 워크플로 (`deploy.yml`) |
| 5 | 실패 분석 워크플로 |
| 6 | 기록과 점검 |
