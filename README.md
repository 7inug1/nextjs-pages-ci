# nextjs-pages-ci

기능 없는 간단한 Next.js 서비스를 GitHub Actions로 검사하고 AWS EC2에 배포하는 학습 프로젝트. CI와 실패 분석 워크플로를 직접 작성했다.

처음에는 정적 내보내기로 GitHub Pages에 배포했다(3, 4단계). TTFB 측정 과제에서 요청마다 서버가 페이지를 그려야 해서, 정적 내보내기와 Pages 배포를 끄고 EC2에서 `next start`로 돌리는 방식으로 바꿨다.

## 계획

| 단계 | 내용 |
| ---- | ---- |
| 0 | 저장소 준비 |
| 1 | 앱과 테스트 |
| 2 | CI 워크플로 (`ci.yml`) |
| 3 | 정적 내보내기 |
| 4 | 배포 워크플로 (`deploy.yml`) |
| 5 | 실패 분석 워크플로 |
| 6 | 기록과 점검 |
| 7 | 서버 렌더링 전환 (정적 내보내기와 Pages 배포 해제, EC2 기준) |
